Personal backup utility

Hermes Backup

Back up selected files from Hermes to the owner's Google Drive using rclone.

What it does

Hermes Backup is a private setup for the owner's own Google accounts. It uses rclone to transfer selected backup files to Google Drive and retrieve them when needed. It is not offered as a public service.

Google Drive access

The owner signs in with Google to authorize the backup connection. The connection uses the drive.file permission, which limits access to files and folders created by the app or otherwise explicitly authorized for it.

See the privacy policy for information about backup data and authorization.
