Hermes Backup

Privacy policy

Last updated: 20 October 2026

Hermes Backup is a personal rclone setup operated by its owner to back up selected files from Hermes to the owner's Google Drive. It is not a public service.

Data access and purpose

Google authorization is used to connect rclone to the owner's Drive. The configured drive.file permission allows access to files and folders created by the app or otherwise explicitly authorized for it. Backup file contents and associated metadata, such as names, sizes and modification times, are processed to transfer, check and restore backups.

Storage and sharing

Backup files are stored in the owner's Google Drive. Rclone stores authorization tokens in its configuration on the machine where the connection is configured. File names and transfer details may also appear in local rclone logs. The owner is responsible for protecting these configurations, logs and backup files.

Google user data is used only for the owner's backup and restore operations. It is not sold, used for advertising, or shared with other users. Google processes data stored in Drive under its own applicable terms and privacy policy.

Retention and control

The owner controls backup retention and can delete backup files in Google Drive. Disconnecting the app does not delete existing backups. The owner can revoke the app's access through Google Account connections and remove locally stored rclone credentials and logs when no longer needed.

Google API data use

Hermes Backup's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.
